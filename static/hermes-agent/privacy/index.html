Privacy Policy: Hermes Agent

Last updated: October 1, 2026

Hermes Agent (homepage) is a personal software tool operated by John You for his own use. It has exactly one user: John. This policy describes how it handles Google user data.

What data it accesses

With John's authorization, Hermes Agent accesses data in John's own Google account through Google's APIs: Gmail messages and labels, Google Calendar events, Google Drive files, Google Docs, Google Sheets, and Google Contacts (read-only). It does not access anyone else's account.

How it uses the data

Only to perform tasks John asks for, or has scheduled, on his own behalf: for example reading newsletters to build a daily briefing, looking up calendar events, or creating a document. Data is not used for advertising, profiling, or training machine-learning models, and is not sold or shared with third parties.

Where it is stored

The OAuth token that lets Hermes Agent act on John's account is stored on a private server that John controls, in a file readable only by his user account. Content from Google services is processed in memory and may be saved on that same server (for example as notes or briefings that John keeps). To perform tasks, relevant excerpts may be sent to the AI model provider John has chosen to run the assistant (Anthropic) solely to produce a response for him, and are subject to that provider's own terms. Nothing is made public.

Limited Use

Hermes Agent's use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including the Limited Use requirements. No humans other than John read the data, except where needed for security, to comply with law, or with John's consent.

Retention and deletion

John can delete any saved content from his server at any time, and can revoke Hermes Agent's access at any moment at myaccount.google.com/permissions, after which the stored token stops working.

Changes and contact

If this policy changes, the date above will be updated. Questions: johnswyou@gmail.com.
